# Alok Kumar Singh - Portfolio

Welcome to the personal portfolio repository of **Alok Kumar Singh**, an aspiring Computer Science Engineer and Innovator.

## Project Overview

This portfolio showcases my projects, skills, and professional journey. It is built with modern web technologies to ensure performance, accessibility, and a premium user experience.

**Live Demo**: [https://aloksingh123321.github.io/portfolio_alok](https://aloksingh123321.github.io/portfolio_alok)

## Tech Stack

- **Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI
- **Animations**: Framer Motion
- **Forms**: Formsubmit.co (Direct Email)

## Features

- **Responsive Design**: Optimized for all devices.
- **Project Showcase**: Detailed view of featured projects like KAVACH and Aaharithm.
- **Direct Contact**: Functional contact form sending emails directly to Gmail.
- **Resume Download**: Dedicated resume page with PDF download capability.

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/aloksingh123321/portfolio_alok.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run development server**:
    ```bash
    npm run dev
    ```
